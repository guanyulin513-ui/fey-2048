# 2048 Multiverse

可直接部署到 GitHub Pages 的原生 HTML/CSS/JavaScript 專案。

## 功能
- Classic Mode：4x4 / 5x5 / 6x6
- Card Mode：倍率卡 / 消除卡 / 洗牌卡
- Block Battle Mode：敵人方塊 / HP / 合併範圍傷害
- 分數 / 最高分 / 暫停 / 重開
- 手機滑動 + 鍵盤操作
- 深色模式
- Web Audio 音效系統
- localStorage 儲存最高分與主題

## 執行
直接開啟 `index.html` 即可，或使用本機伺服器：
```bash
python -m http.server 8000
